# Somon

Веб-приложение для управления образовательным центром **Somon**.

- **Публичный сайт:** курсы, преподаватели, новости, материалы, контакты, заявки на обучение.
- **Студент:** курсы и прогресс, расписание-календарь, материалы (файлы, видео), задания с ответом текстом и файлами и историей попыток, оценки, посещаемость, уведомления, активность, профиль с фото.
- **Преподаватель:** группы и карточки студентов, посещаемость, задания и работы «На проверке», оценки с комментариями, материалы, объявления, аналитика, расписание.
- **Администратор:** пользователи, студенты, преподаватели (курсы, группы, фото, статус), заявки на курсы, курсы, группы, расписание, филиалы и аудитории, задания, материалы (курсов и сайта), объявления, новости, уведомления, статистика, настройки сайта.

## Стек

- **Frontend:** Next.js 15 (App Router), TypeScript, CSS
- **Backend:** Node.js, Express, Prisma
- **БД:** SQLite (по умолчанию, без Docker) · опционально PostgreSQL через Docker Compose
- **Auth:** JWT в httpOnly cookie

## Требования

- Node.js 20+
- npm 10+
- (опционально) Docker для PostgreSQL

## Быстрый старт

### 1. Backend

```bash
cd backend
cp .env.example .env
npm install
npx prisma db push
npm run db:seed
npm run dev
```

API: http://localhost:4000  
Health: http://localhost:4000/api/health

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение: http://localhost:3000

Браузер обращается к API через тот же адрес: Next.js проксирует `/api` и `/uploads` на бэкенд
(`BACKEND_URL`, по умолчанию `http://localhost:4000`), поэтому cookie входа работает на любом домене.

### Показать проект по публичной ссылке

```powershell
powershell -ExecutionPolicy Bypass -File .\start-online.ps1   # -Build — пересобрать
```

Скрипт запускает бэкенд и фронтенд в продакшен-режиме и выдаёт временную ссылку
`https://….trycloudflare.com`. Ссылка работает, пока открыто окно скрипта и включён компьютер;
при каждом запуске адрес новый.

## Сценарий демонстрации (защита)

1. Войти как `admin@somon.local` — Dashboard: заявки, занятия сегодня, последние действия.
2. **Курсы** → создать курс; **Группы** → создать группу, назначить преподавателя, добавить студентов.
3. **Расписание** → добавить онлайн-занятие (ссылка) и офлайн-занятие (филиал, аудитория).
4. Войти как `teacher1@somon.local` — открыть группу, добавить материал (файл + видео), создать задание.
5. Войти как `student1@somon.local` — курс, ближайшее занятие, открыть материал, скачать файл.
6. Отправить ответ на задание: текст + файл.
7. Вернуться к преподавателю — «На проверке», скачать файл, выставить оценку с комментарием.
8. Вернуться к студенту — уведомление, оценка и комментарий, обновлённый прогресс, история активности.

## Переменные окружения (backend)

См. `backend/.env.example`. Для продакшена обязательно задайте свой `JWT_SECRET`.
Лимит загружаемых файлов — `MAX_FILE_SIZE_MB` (по умолчанию 20).

## Обновление существующей установки

Схема БД меняется только через Prisma. После получения новой версии:

```bash
cd backend
npm install
npx prisma db push   # новые поля и связь преподаватель ↔ курсы
npx prisma generate
```

Запись на курс со стороны студента идёт через заявку: администратор одобряет её в разделе
**Заявки на курсы** с выбором группы, после чего студент получает доступ к курсу.

Для PostgreSQL:

1. `docker compose up -d`
2. В `backend/.env`: `DATABASE_URL="postgresql://somon:somon@localhost:5432/somon?schema=public"`
3. В `prisma/schema.prisma` сменить `provider` на `postgresql`
4. `npx prisma db push && npm run db:seed`

## Формула прогресса

`0.4 × %завершённых занятий + 0.4 × %выполненных заданий + 0.2 × %посещаемости`

Опоздание и уважительная причина считаются присутствием.
