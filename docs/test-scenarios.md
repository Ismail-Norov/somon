# Тестовые сценарии

1. Регистрация и вход пользователя.
2. Студент открывает `/admin/dashboard` — редирект / нет доступа к данным API.
3. Преподаватель видит только свои группы.
4. Админ создаёт курс.
5. Админ создаёт группу и назначает преподавателя.
6. Админ добавляет студента в группу.
7. Админ/преподаватель создаёт занятие (конфликт расписания блокируется).
8. Преподаватель отмечает посещаемость.
9. Преподаватель создаёт задание — студенты получают уведомление.
10. Студент отправляет ответ.
11. Преподаватель выставляет оценку — уведомление студенту.
12. Прогресс студента пересчитывается.
13. Изменение расписания создаёт уведомление.
14. Поиск пользователей/курсов работает.
15. Адаптив: боковое меню сворачивается на узком экране.
16. Пустые списки показывают Empty State.
