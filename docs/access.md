# Роли и права доступа

| Раздел | Студент | Преподаватель | Администратор |
|--------|---------|---------------|---------------|
| Профиль | свой | свой | любой |
| Курсы | свои / каталог | связанные | CRUD |
| Группы | свои | свои | CRUD |
| Расписание | свои | свои + управление | CRUD |
| Посещаемость | просмотр | свои группы | просмотр/коррекция |
| Оценки | свои | свои группы | просмотр/коррекция |
| Материалы | своих курсов | CRUD своих | CRUD |
| Задания | сдача | CRUD + проверка | CRUD |
| Пользователи | нет | связанные студенты | CRUD |
| Статистика | своя | свои группы | весь центр |

Сервер отклоняет доступ к чужим группам/студентам даже при прямом запросе по ID.
